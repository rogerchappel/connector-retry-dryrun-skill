# User feedback

This project is local-first and does not collect telemetry. Feedback is
voluntary: users can open a GitHub issue in
[rogerchappel/connector-retry-dryrun-skill](https://github.com/rogerchappel/connector-retry-dryrun-skill/issues)
or submit a pull request. No account beyond GitHub is needed to use the
software; sharing feedback publicly is optional.

When reporting an experience, please include the command or workflow used,
what you expected, what happened, and the package version or commit. Use a
sanitized example if useful. Do not include connector credentials, customer
content, private logs, or other sensitive data. Report security concerns
privately through the repository's GitHub security reporting page rather than
posting sensitive details in a public issue.

Maintainers should ask before attributing a quotation or identifying a user in
project documentation. Record only feedback the person has consented to share;
otherwise summarize it anonymously and omit identifying details. A feedback
note should capture the date, context, observation, and consent/attribution
status, without retaining unnecessary personal data.
